PSVT-R Instructions

This test consists of 10 questions designed to see how well you can visualize the rotation of three dimensional objects.


You are to:

  1. Study how the object in the top line of the question is rotated.
  2. Picture in your mind what the object shown in the middle line looks like when rotated in exactly the same manner.
  3. Select the correct answer from A, B, C, D or E.

Each question has only ONE correct answer.
